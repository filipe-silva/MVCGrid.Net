NuGet

Available from NuGet:

  • MVCGrid — the portable core (netstandard2.0)
  • MVCGrid.MvcWeb — classic ASP.NET MVC adapter (net48)
  • MVCGrid.AspNetCore — ASP.NET Core MVC adapter (net8)
  • MVCGrid.Wasm — browser/WebAssembly host adapter (netstandard2.0, no server)

PM> Install-Package MVCGrid.MvcWeb

PM> Install-Package MVCGrid.AspNetCore

PM> Install-Package MVCGrid.Wasm

Live Demo

Try every feature in the live showcase — the demo site runs the same grid engine entirely in your browser via .NET WebAssembly (the MVCGrid.Wasm package), no server involved.
