Getting Started

Prerequisites

  • ASP.NET MVC 3 or greater, or ASP.NET Core MVC
  • jQuery
  • Bootstrap 3 (Or you can create your own custom style.)

Installation

ASP.NET Core MVC

  1. Install the NuGet Package

    PM> Install-Package MVCGrid.AspNetCore

  2. Register the services and endpoint in Program.cs: 
    builder.Services.AddMVCGrid(o => { o.HandlerPath = "/mvcgrid"; });
// register grids into MVCGridDefinitionTable at startup
app.MapMVCGrid();
  3. Add the javascript reference to your _Layout page after jquery is referenced: 
    <!-- Be sure this is after jquery reference -->
<script src="/mvcgrid/script.js"></script>
  4. Use the grids in your view by adding the using @using MVCGrid.AspNetCore and then the html helper @Html.MVCGrid("YourGridName")

Classic ASP.NET MVC

  1. Install the NuGet Package

    PM> Install-Package MVCGrid.MvcWeb

  2. Add the following to your web.config: 
    <system.webServer>
  <handlers>
    <add name="MVCGridHandler" verb="*" path="MVCGridHandler.axd" type="MVCGrid.Web.MVCGridHandler, MVCGrid.MvcWeb" />
  </handlers>
</system.webServer>
  3. Add the javascript reference to your _Layout page after jquery is referenced: 
    <!-- Be sure this is after jquery reference -->
<script src="~/MVCGridHandler.axd/script.js"></script>
  4. Add your grid definitions to a MVCGridConfig.cs file under the App_Start folder and call MVCGridConfig.RegisterGrids() from Application_Start() in Global.asax. See below for example.
  5. Use the grids in your view by adding the using @using MVCGrid.Web and then the html helper @Html.MVCGrid("YourGridName")

Browser (WebAssembly)

  1. Install the NuGet Package (in a .NET WebAssembly browser app)

    PM> Install-Package MVCGrid.Wasm

  2. Register your grids at startup, then run the engine in-process — no server needed: 
    // register grids into MVCGridDefinitionTable at startup, then:
var renderer = new WasmGridRenderer(new WasmGridOptions { HandlerPath = "mvcgrid" });

string pageHtml = renderer.GetBasePageHtml("YourGridName", currentUrl); // the @Html.MVCGrid equivalent
string fragment = renderer.RenderData(requestUrl);   // answers MVCGrid.js's AJAX request in-process
string script   = renderer.GetClientScript();        // the unchanged MVCGrid.js, ready to inject
  3. Answer the client script's one AJAX call from a jQuery ajaxTransport shim and turn exports into Blob downloads — this very site is the reference implementation (MVCGrid.Example.Wasm in the repo).

Non-Fluent Example

You can also configure the grids using the non-fluent method if you prefer.

GridDefinition<YourModelItem> def = new GridDefinition<YourModelItem>();

GridColumn<YourModelItem> column = new GridColumn<YourModelItem>();
column.ColumnName = "UniqueColumnName";
column.HeaderText = "Any Header";
column.ValueExpression = (i, c) => i.YourProperty;
def.AddColumn(column);

def.RetrieveData = (options) =>
{
    return new QueryResult<YourModelItem>()
        {
            Items = new List<YourModelItem>(),
            TotalRecords = 0
        };
};

MVCGridDefinitionTable.Add("NonFluentUsageExample", def);

Setting Defaults

To set defaults for multiple grids, create a GridDefaults object and set the desired properties. Then pass that GridDefaults object into the GridBuilder or GridDefinition when creating it.

GridDefaults defaultSet1 = new GridDefaults()
{
    Paging = true,
    ItemsPerPage = 20,
    Sorting = true,
    NoResultsMessage = "Sorry, no results were found"
};

MVCGridDefinitionTable.Add("UsageExample",
    new MVCGridBuilder<YourModelItem>(defaultSet1) // pass in defaults object to ctor
    .AddColumns(cols =>
    {
        // add columns
    })
    .WithRetrieveDataMethod((context) =>
    {
        //get data
        return new QueryResult<YourModelItem>();
    })
);
